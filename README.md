# UX/UI Pro - Лендинг курса UX/UI-дизайна

Интерактивная посадочная страница курса «UX/UI-дизайн с нуля» на чистом HTML, CSS и JavaScript.

## Особенности

- ✅ Полностью адаптивный дизайн (мобильные и десктопные устройства)
- ✅ Темная минималистичная тема
- ✅ Цветовая схема: #FAE93D (желтый) и #F41FFF (фиолетовый)
- ✅ Фиксированный header с плавной навигацией
- ✅ Бургер-меню для мобильных устройств
- ✅ Интерактивные 3D SVG-иконки с анимациями
- ✅ Аккордеон программы курса
- ✅ Валидация формы регистрации
- ✅ Hover-анимации на всех интерактивных элементах
- ✅ Логотипы компаний в отзывах

## Структура файлов

```
html-landing/
├── index.html      # Основная HTML-разметка
├── styles.css      # Все стили CSS
├── script.js       # JavaScript функциональность
└── README.md       # Документация
```

## Запуск

Просто откройте файл `index.html` в браузере. Для разработки рекомендуется использовать локальный сервер:

### С помощью Python:
```bash
cd html-landing
python -m http.server 8000
```
Затем откройте http://localhost:8000

### С помощью Node.js (http-server):
```bash
cd html-landing
npx http-server -p 8000
```

### С помощью VS Code:
Используйте расширение "Live Server"

## Секции страницы

1. **Header** - Фиксированная навигация с бургер-меню
2. **Hero** - Главный баннер с призывом к действию
3. **Преимущества** - 4 карточки с 3D иконками
4. **Программа** - Аккордеон с 8 модулями
5. **Отзывы** - 3 отзыва студентов с логотипами компаний
6. **Регистрация** - Форма с валидацией
7. **Финальный CTA** - Повторный призыв к действию
8. **Footer** - Контакты и информация

## JavaScript функциональность

- Плавная прокрутка по якорям
- Открытие/закрытие бургер-меню
- Аккордеон (только один открыт одновременно)
- Валидация формы (обязательные поля, проверка email)
- Имитация отправки формы
- Подсветка активной секции в навигации
- Hover-анимации

## Цветовая палитра

- Основной фон: `#0a0a0a`
- Акцентный желтый: `#FAE93D`
- Акцентный фиолетовый: `#F41FFF`

- Планшеты: 768px - 1023px
- Десктоп: ≥ 1024px

## Модификация

### Изменение цветов
Найдите и замените цветовые коды в `styles.css`:
- `#FAE93D` - желтый
- `#F41FFF` - фиолетовый

### Добавление модулей
Скопируйте структуру `.accordion-item` в секции программы

### Изменение контента
Весь контент находится в `index.html` и легко редактируется
